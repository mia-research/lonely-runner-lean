## Method (all exact Fraction)

The windows are the closed gaps of their union inside [1,23] (a gap [e,s] with e = s is a single-point window; a point is clear when it lies in no open zone). Checks run on every member: (i) endpoints and midpoint of each window are clear by `blocks()` (exact position test of `path()`); the midpoint of every gap between windows is blocked; (ii) first window starts at the `path()` landing R*; (iii) for J1, first window width equals `outcome()['width']`.
