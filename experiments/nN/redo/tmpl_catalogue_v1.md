## 1. Definitions and scripts
- Template of an arrangement: the ordered list, left to right, of the windows of K6 = `clear_components(readings 1..6, H=7)`; each window [a,b] is stored as (left labels, right labels, one-point flag). Left labels of the value a: `R1` if a = 1, and `xY.J` for every zone Z(Y,J) of a reading Y in 1..6 with (8J+1)/rho_Y = a (exit). Right labels of b: `R7` if b = 7, and `eY.J` for every zone with (8J-1)/rho_Y = b (entry). Several labels at one end (a tie, written `&`) are all kept; `pt` marks a = b. Every window end received at least one label (assertion in `template`).
- `tmpl_lib_v1.py`: `template`, `gate`, `r2_set`, labels. `r2_set(rhos)` = (rho_7 > rho_6) intersected, over the windows [a,b], with the union over j >= 1 of the open intervals ((8j-1)/a, (8j+1)/b); exact; returns the list of open intervals.
- `tmpl_collect_v1.py SRC start end` -> `tmpl_rec_*_v1.pkl`, logs `tmpl_collect_J1_v1.out`, `tmpl_collect_rest_v1.out`. Gate flag by `in_zone7`; every flagged member re-checked with `outcome()['R'] > 7`; every 50th unflagged member re-checked with `outcome()['R'] <= 7`.
- `tmpl_r2_v1.py` -> `tmpl_r2_*_v1.pkl`, log `tmpl_r2_run_v1.out`. For every distinct crosser: own rho_7 lies in R2 (exact), and `outcome()['R'] > 7` at the midpoint of the top component and of the component containing rho_7.
- `tmpl_analyse_v1.py` -> `tmpl_analyse_v1.out` (all tables below). `tmpl_supj_v1.py` -> `tmpl_supj_v1.out`.
- Check results: gate flag against `outcome` landing: J1 7,567 crossers + 217 unflagged checked, 0 violations; J2 7,636 crossers + 5,277 unflagged checked (2,000 + 1,993 + 1,284), 0 violations; seeds 11,176, 0 violations. R2: 16,152 tuples, 0 failures (own rho_7 in R2; midpoints give landing > 7), 0 unbounded.

## 7. Exceptions and limits
1. Sources are stored points (one member per outcome region, J1 and J2), the seeds (landing > 9) and X24, not a draw from any distribution; every count is for these sets. J2 crossers lie only at indices >= 100,000 of the stored list (order of storage).
2. The seeds overlap J1/J2 (7,355 tuples in several sources) and the two J3w sets are rationalisations of the same 716 witnesses at two denominators; counts of tuples per source are not additive.
3. Stability of the 115 templates is shown for random orders within these sources (new templates in the last 1,000: 1, 0, 0). In rho_7 order the templates in [15,16) were not predicted by the lower ones (7 new). No crosser with rho_7 in [11,15) was reached; J3 was not run; rho_7 > 16.5 is represented by X24 alone.
4. 23 templates carry tied labels (several zones with the same endpoint); labels are kept as sets, so a tie-free perturbation of such a tuple may have a different template. Not tested.
5. R2 gives the supremum of an open set; it is not attained. The midpoint checks use `outcome` at interior points; the endpoints were not tested.
6. In `tmpl_analyse_v1.out` the line "min rho_2..rho_6" carries the labels 3..7 for the minima of rho_2..rho_6 (labelling slip, values exact; corrected in sec. 3).
7. The `.out` of the analysis prints one label "fraction-free count"; it is a count of non-crosser members with <= 6 windows (45,240 of 274,610).
8. Process: an early foreground run was cancelled by `pkill` (no output used); a first draft of `r2_set` enumerated every j for narrow windows and did not terminate; it was replaced by the closed-form top-j bound in the saved `tmpl_lib_v1.py`. One process at a time throughout; each run under 10 minutes (longest 116 s).
9. Template is a statement about which zones bound each window. The numeric R2 interval depends on the six readings and on a lap j of reading 7 that the template does not contain.
