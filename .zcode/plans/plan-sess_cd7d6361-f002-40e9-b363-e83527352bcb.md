## CM-vanishing test for the E3 anomaly — pre-registrable plan

### Objective (lens prediction, binary falsifier)

The freed lens predicts the E3 anomaly ($E_3=13125$ on secp's real 82) is **CM-driven**: the $j=0$ endomorphism $\phi:(x,y)\mapsto(\omega x,y)$ biases the cubic-residue classes of the $X$-distribution, and this bias is what $E_3$ detects. The falsifier: **map the same 82 real private keys $d$ onto a non-CM curve $E'$ (same prime) and re-compute $E_3$.**

- **FAIL-TO-REJECT on $E'$** ⟹ anomaly does not survive the curve change ⟹ **CM-driven** (lens confirmed; the freed-rule avenue on this surface is CM×band structure, not $d$-structural leakage; the secp result is a curve fingerprint, not a key fingerprint).
- **REJECT-HIGH on $E'$** ⟹ anomaly survives the curve change ⟹ **$d$-driven** — the 82 puzzle $d$'s themselves carry cubic-residue structure independent of the curve. This is a much bigger lead: it points at the puzzle generator / PRNG fingerprint and upgrades Frontier #29's group-law objects to first priority.

Either outcome is informative and publishable as a scoped empirical result.

### Step 1 — Select and verify the non-CM curve $E'$

- $E': y^2 = x^3 + x + 1$ over $\mathbb{F}_p$, $p$ = secp's prime. $j = 1728\cdot 4/(4+27) = 6912/31 \notin\{0,1728\}$ ⟹ non-CM, no extra automorphisms. Verify $4a^3+27b^2 = 31 \not\equiv 0\pmod p$ (trivially true).
- Sage: `Eprime = EllipticCurve(GF(p),[1,1])`; `Nprime = Eprime.order()`. Hasse bound guarantees $|N' - p| \le 2\sqrt p$. If $N'$ prime, any non-identity point is a generator. If cofactor $h'>4$, retry with $y^2=x^3+2x+3$ etc. until cofactor $\le 4$.
- Find generator $G'$ of order $n' = N'/h'$ with $n'>2^{254}$ (required so $[d]G'$ is well-defined for all puzzle $d\in[1,2^{130})$).
- Record $E', p, a, b, N', h', n', G'$ to a frozen-meta JSON.

### Step 2 — Re-derive the 82 X-coords on $E'$ from the real $d$'s

- Read `solved_puzzles_xy.csv` column `private_key` (the 82 real $d$'s — already confirmed present).
- For each $d$: $X'_i = x([d]G')$ on $E'$. 82 scalar mults, trivial (<1 sec).
- Save `solved_puzzles_xy_Eprime.csv` (same columns + `X_Eprime`, `Y_Eprime`).

### Step 3 — Build the $E'$-matched null (the load-bearing prep)

- Take the **same** 100,023 $d$-values from `constructed_keys_1to160_100k.csv` (known-MT19937, same bit-lengths as real 82). This is the matched null pool — isolates the curve variable perfectly (same $d$-distribution, different curve).
- Pre-compute $[d]G'$ for all 100,023 constructed $d$'s ONCE, cache X-coords to `constructed_keys_Eprime_100k.csv`. (~2–5 min of EC ops; done once, then the inner loop is field arithmetic only — matches existing secp workflow.)
- **Freeze the $E'$ null**: 10,000 resamples of 82 (one $X'$ per matching real bit-length), compute $E_3$ for each, build order statistics. Freeze region $[L', U']$ at upper/lower 0.025 tails (two-sided $\alpha\approx0.05$), seed frozen. Save `diffset_cubic_Eprime_frozen_null_v1.npy` + meta JSON.
- **The secp frozen region `[84,11997]` is NOT reused** — $E'$ gets its own region from its own null. This is the gate-discipline-critical step.

### Step 4 — Controls (mirror existing E3 prereg, must fire)

- **Forced-structure**: $E_3 \equiv 0 \pmod 3$ for $n=82$ — automatic bug-check, asserted.
- **Planted-firing control on $E'$**: concentration plant $\varepsilon$ (reassign $\varepsilon\cdot3321$ pairs to one class) must reject-high at $\varepsilon=0.05$ with power $\ge 0.9$ (calibrate on $E'$ null). If the planted control does not fire on $E'$, the test is void — instrument failure, not a null result.
- **Independent cross-check regen** (fast gmpy2 path, 2000 resamples, seed 4242) — confirm frozen null shape.

### Step 5 — Apply: the decision

- Compute $E_3(X'_{\text{real}})$ on the 82 $E'$-derived X-coords. Exact integer path (gmpy2 if available).
- Assert forced-structure ($E_3\equiv0\bmod 3$, sum=3321).
- Decision vs frozen $[L', U']$:
  - $E_3' > U'$ → **REJECT-HIGH** → $d$-driven → major lead (puzzle generator / PRNG fingerprint; escalate Frontier #29).
  - $E_3' < L'$ → REJECT-LOW → over-uniformity on $E'$ (unexpected; characterize, don't interpret yet).
  - else → **FAIL-TO-REJECT** → CM-driven → lens confirmed, freed-rule avenue on this surface is curve-structural not key-structural.
- Rank-$p$: $\min((\#\{A'\ge E_3'\}+1)/(N+1),(\#\{A'\le E_3'\}+1)/(N+1))\cdot 2$.

### Scope, banners, files

- **Scale banner**: keys are real secp $d$'s (256-bit), mapped to $E'$ over the same $p$. No claim about other primes.
- **Language rules**: `secure`/`closure`/`proven hard`/`unbreakable` forbidden. This is a characterization, not a verdict.
- **Anomaly-drill rule**: output = characterization of the E3 anomaly's CM-dependence, never a security verdict.
- **Multiple comparisons**: this is 1 statistic on $E'$, but sits alongside the secp E3 ($p\approx0.033$, 1 of ~7). Report both; do not claim independence.
- **Lens tagging**: the CM-driven prediction is a lens-generated conjecture; the test result is empirical either way. Tag accordingly.
