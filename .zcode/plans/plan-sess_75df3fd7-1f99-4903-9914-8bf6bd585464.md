## Plan: PREREG v4 — Semaev CM Relation-Yield Scaling Extension

### Objective
Test whether T1 (CM yield advantage on random V, #E matched) continues to grow with |V| beyond the two points (|V|=4,5) tested in v3, or whether it saturates. This is the explicitly named "next probe" from the v3 A1 verdict.

### Pre-registration document: `PREREG_semaev_cm_relation_yield_v4.md`

### Design

**Hypothesis:**
- H1 (primary, same as v3): matched-#E paired T1 = logQ_CM − logQ_nonCM. One-sided (CM higher).
- **Scaling (primary, the new test):** T1 as a function of |V|. Pre-committed models:
  - **M_flat:** T1 = constant (bounded effect)
  - **M_linear:** T1 = a·|V| + b (grows linearly)
  - **M_log:** T1 = a·log|V| + b (logarithmic growth — still super-constant but sub-linear)
  - Verdict by likelihood ratio / AIC on the |V|-point data, with permutation-calibrated thresholds.

**Scope:**
- m=3 (same as v3 — S₄ builds instantly, cells are seconds)
- |V| ∈ {4, 5, 6, 7, 8, 9} — 6 levels (4 and 5 replicate v3 for comparability; 6-9 are new)
- Same 24 primes p∈[523, 823] (frozen schedule from v3, deterministic seed reuse)
- K=25 targets per cell (same as v3)
- j0 and j1728 as separate CM levels (same as v3)

**Compute estimate:** 6 |V| levels × 24 primes × ~7 curves × 25 targets = ~25K `measure_system` calls. At |V|=9 the Macaulay matrix has ~9K columns (vs ~3K at |V|=5). Estimate 12-24 hours wall time on the current machine (two Sage processes, each at ~95% CPU).

**Statistics:**
- H1 per |V|-level (same sign-flip null as v3)
- Scaling: fit T1(|V|) to M_flat, M_linear, M_log. Likelihood ratio test (permutation-calibrated) to distinguish flat from growing. Pre-committed: if the linear or log model significantly outperforms the flat model (permutation p < 0.01), Scaling verdict = GROWS.
- H2 (x-closure): same mu3 lever test at each |V|, tests whether R2 changes with |V|.

**Controls:** C1 (plant), C2 (#E-match), C3 (|V| equality), C4 (nonCM vs nonCM null), C5 (group-law). Same as v3.

**Instrument changes:**
- `semaev_cm_relation_yield_v4.py` — fork of v3, extended to sweep |V| from extra=1 to extra=6
- No changes to `semaev_elimination_v1.py` — the frozen instrument is reused unchanged
- Schedule SHA frozen before first quo (same pattern as v3)

### Risk mitigations
- |V|=9 cells may be slower than expected → the run script logs per-cell timing and allows resumption if interrupted
- The `decomposable_target` function may fail more often at larger |V| (more x-coords to make distinct) → the K=25 target count is a ceiling; cells with fewer valid targets are logged but included with reduced weight
- If the experiment exceeds the time box, we can truncate to |V|∈{4,5,6,7,8} and still have 5 |V|-points (adequate for Scaling)
