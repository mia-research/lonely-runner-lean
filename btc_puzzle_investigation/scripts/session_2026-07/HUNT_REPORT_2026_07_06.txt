METHODOLOGY
─────────────────

DESIGN:
  (A) Per-n hunt: For each n with >=300 keys, test whether (X,Y) features
      statistically leak k within that group (using adjusted MI).
  (B) Per-k hunt: For each k with >=300 keys, test whether (X,Y) features
      statistically leak n within that group.

FEATURES (strictly derived from X, Y, and curve constants P, BETA):
  - Residues: X%m, Y%m for m ∈ {2,3,4,5,7,8,9,11,13}
  - Legendre symbols: X_leg_p, Y_leg_p for p ∈ {3,5,7,11,13}
  - Bit operations: X_bit_b, Y_bit_b for b ∈ [0,8)
  - Slope: (Y/X) mod m for m ∈ {2,3,5,7,11,13}
  - GLV endomorphism: (BETA·X) mod P, mod m for m ∈ {2,3,5,7,11,13}
  
  Total: 56 features, all with alphabet size <= 13 to avoid large-alphabet MI bias

TARGETS (what we tried to predict within each group):
  - k targets: k%m for m ∈ {2,3,4,5,7,8,9,11,13}
  - n targets: n%m for m ∈ {2,3,4,5,7,8,9,11,13}
  Total: 9 targets each direction

METRIC: Adjusted Mutual Information (bits) = raw MI - mean(shuffle baseline)
  - Shuffle baseline: mean MI over 8 random permutations of target
  - Removes bias inherent in small-sample MI estimation
  - Positive value indicates dependence above independence null

NULL HYPOTHESIS:
  H0: (X,Y) and (n,k) are independent within each group
  Null threshold: 99th percentile of shuffle MI values across all tests
  Expected false-positive rate: 1% of all tests
