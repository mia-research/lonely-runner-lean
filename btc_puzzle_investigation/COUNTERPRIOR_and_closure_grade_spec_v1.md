## Criterion used
A rule is *insidious* if it makes the rewarded/default move a **closure**
("known / generic / vacuous / a wall / says nothing") rather than building the
object — especially when it launders a true fact or a training prior into that
closure.

## Worked-example errors (session 2026-07-28 — the decidable artifacts)
1. **"Leakage must be computational, not information-theoretic."** Derived from
   the true fact `I(k;P)=H(k)` (the key is determined by its public point). The
   move *erased an open channel*: the ensemble / derived-feature **statistical**
   structure (channel 2), distinct from single-instance determinacy (1) and
   computational advantage (3). `(1)` constrains neither `(2)` nor `(3)`.
   Relationship facts: `(2)` small ⇒ `(3)` small; `(2)` large ⇏ `(3)` large (the
   PRNG case); an *efficient test that fires* is evidence in both. Only the narrow
   point survives — a statistical **null** cannot certify computational security,
   and it runs both ways (does not certify a break either).
2. **"Single-instance info-theoretic secrecy is vacuous."** Over-read
   determinacy. `H(k|P)=0` is universal (bijectivity of `k↦kG`; all instances,
   proven not tested) but establishes ONLY zero *residual entropy* — the key is
   not *hidden*. It does NOT establish absence of *structure*. **Determined ≠
   structureless.** A closure-from-a-fact one level inside the "safe" bucket.

## Structural findings
- **F1 (asymmetry).** The corpus polices overclaim *upward* (don't say
  PROVED/closed/decisive unless it is) and is near-blind *downward* (calling an
  avenue closed/generic/vacuous). The grade vocabulary
  (PROVED/VERIFIED/CITED/EMPIRICAL/heuristic) has **no tag for a dismissal**, so
  closures bypass the discipline entirely.
- **F2 (analytical-closure trust).** The stance "only a rigorous ANALYTICAL proof
  closes" guards empirical nulls but *trusts* analytical closures — the subtlest
  false-closure vector. Both errors above were analytical, via a moved
  quantifier/object.
