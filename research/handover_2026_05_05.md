## 2. THE one universal open problem (was: "three open items")

### 2.0 Universal framing

**The single phenomenon driving all three "open items":**

For any n ≥ 3, unit runner ρ ∈ U(n) with actual speed e_ρ = ρ + q_ρ·n at fibre r = n + j (k=1 band), the floor T_ρ(j) := ⌊e_ρ·r/n²⌋ satisfies

> **Universal Floor Decomposition.** T_ρ(j) = M(q_ρ, j) + ε(ρ, j), where
> M(q, j) := q + ⌊qj/n⌋ and ε(ρ, j) := ⌊((q_ρj mod n) + ρ + ⌊ρj/n⌋)/n⌋ ∈ {0, 1, 2}.

This holds for **every** n (verified for n ∈ {15, 21, 25, 33, 35, 49, 55} including squarefree, prime-power, and mixed; the proof is by direct computation independent of n's factorization — see Lemma N-PSQ-T03(a) in [`lrc_proof.py`](lrc_proof.py:911) §13).

**Universal Mod-π Blocking Criterion.** For each prime divisor π of n and each d ∈ πZ ∩ Z/nZ \\ {0}: bad_set(ρ, T_ρ(j), n) ∋ d requires T_ρ(j) ≡ 0 or T_ρ(j) ≡ -1 (mod π). (Same Lemma N-PSQ-MOD argument, applied prime-by-prime.)

**Universal Safe-q Regime.** For each prime divisor π of n: if q_ρ ∈ [1, ⌊(π-3)/2⌋], M(q_ρ, j) mod π ∈ {q_ρ, …, 2q_ρ-1} ⊂ {1, …, π-4}, avoiding the bad set {0, π-3, π-2, π-1}. Hence ρ does not block any d ∈ πZ\\{0} at any j.

**Therefore the universal Tier-1 question is:**

> **Universal Conjecture (LRC-Tier1-UNIV).** For any n ≥ 3 with at least one unit runner present, any (q_ρ)_{ρ ∈ U(n)} with q_ρ ≥ 0, and any retained-runner speed set E with two dropped residues (d₁, d₂) ∈ (Z/nZ\\{0})²: there exists a fibre r at which all retained runners are lonely AND d₁, d₂ are uncovered by every unit runner.

The three previously-listed "open items" (A, B, C) are all **instances** where the universal mechanism has not yet been pushed to closure — not separate problems. The branching happened because the proof's HISTORY layered case-specific fixes (Silence Fibre for rep-speeds, period-staircase for n=15, Lemma N-PSQ-T03 for n=p² low-q) without unifying to the universal claim.

**What the universal mechanism still owes:**

> **Universal Open Step.** Bound the joint blocking from unit runners with q_ρ in the "bad regime" (q_ρ ≥ ⌈(π-1)/2⌉ for some prime divisor π of n). Specifically, show that for each (d₁, d₂), the set of j ∈ k=1 band with d₁ or d₂ ∈ ⋃_ρ bad_set(ρ, T_ρ(j), n) is **strictly less than the band size** p(p-1) (for n=p²) or φ(n) (for general n).

This is a single combinatorial-counting problem with one universal flavour: **structural cancellation of high-q unit-runner blocking via the K-sum-like constraint Σ_ρ T_ρ(j) ≡ (function of j, Q) (mod π) for each prime divisor π.** Solve it once → all three "open items" close simultaneously.

## 5. Key technical insights to carry forward

1. **The exact floor decomposition T_ρ(j) = M(q_ρ,j) + ε(ρ,j), ε ∈ {0,1,2}** (Lemma N-PSQ-T03(a)) is the fundamental analytic tool for n=p². It separates the q-dependence (M) from the ρ-dependence (ε), and reduces the mod-p blocking criterion to a 4-element residue condition on M. This decomposition is unique to k=1 band; analogous decompositions for k ≥ 2 are not yet derived.

2. **The K-sum constraint (Lemma N-PSQ-KSF) gives a single linear relation** Σ_ρ K_ρ ≡ jQ (mod p) — but only if K is correctly defined as T_ρ mod p² (or some quantity matching that mod p). Verify this before relying on it.

3. **For q_ρ ≥ 1, T_ρ is strictly increasing in j** with steps in {⌊q_ρ/n⌋, ⌈q_ρ/n⌉} (steps ≥ 1 for q_ρ ≥ n, steps ∈ {0,1} for q_ρ < n). Each integer T-value has ≤ 1 j-preimage when q_ρ ≥ n; per-(ρ,d) blocking ≤ n/q_ρ ≈ p²/q_ρ.

4. **Empirical concentration:** in random adversarial tuples with q_ρ ∈ {0,1,2}, blocking is concentrated in a single (ρ, d) pair (one ρ has its q_ρ "in a bad residue class mod p"). This suggests the structural cancellation argument should exploit the SPARSITY of (ρ, d) blocking pairs, not their counts.

5. **For Items B/C: the period-staircase structure (n=15) used the divisibility chain p | n, q | n, p < q, and the specific fibre b* = (n-1)L/n.** Generalizing to n=pq requires understanding which (p, q) admit analogous chains, and which require a different structural lemma.

## 8. Methodology note (for self-discipline)

This handover was rewritten on 2026-05-05 after the user flagged the original draft as exhibiting the **branching anti-pattern** (per MEMORY.md "Proof Methodology — Handling Exceptions"):

> When a proof case fails or requires an exception, do NOT immediately branch. Instead understand WHAT the exception is, find WHAT CHANGES on either side of the boundary; usually the same conclusion holds via the same mechanism. Only branch when the proof conclusion genuinely differs.

The original draft listed three Tier-1 open items (A/B/C) as if they were separate problems requiring separate techniques. The corrected framing identifies the universal mechanism (Floor Decomposition + Mod-π Blocking + Safe-q Regime + Joint-Blocking Bound), valid for **every** n ≥ 3 and **every** prime divisor π | n, and routes the proof through one universal step instead of three case-specific lemmas. The "open items" are not separate — they are instances where the universal mechanism's joint-blocking bound has not yet been pushed to closure.

**Continued discipline at the start of every continuation session:** before adding any new lemma or case-specific argument to [`lrc_proof.py`](lrc_proof.py) §13, check whether it would generalize to all n. If yes, state it universally. If no, articulate precisely WHY it must be case-specific (which prime-divisor structure breaks the universal claim, and how) — only then introduce the branch.
