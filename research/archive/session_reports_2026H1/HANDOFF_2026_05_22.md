### Sorry 2: CRT Measure Factorization (Line 627)
**Difficulty**: High | **Estimated**: ~50-80 lines | **Closeable**: After Sorry 1

Prove the measure factorization in the sum_factorization proof:
```
∑_m μ(cell_m ∩ {fract(p*t) ∈ A}) = (1/L) * μ(A)
```

**Implementation approach** (from user guidance):
- Avoid `MeasureTheory.Measure.prod`; use direct cell computation
- On each cell m with m ≡ 0 (mod L):
  - fract(L*t) depends only on m mod L = 0
  - fract(p*t) depends only on m mod p
- As m ranges over p cells, m mod p covers {0,...,p-1}
- So {p*t} uniformly covers [0, 1)
- Use `Finset.sum_product'` to decompose the sum
- Apply `MeasureTheory.measure_restrict_apply`

**Key lemmas**: `MeasureTheory.measure_restrict_apply`, `Finset.sum_product'`, `cell_fract_props`

### Sorry 3: Periodicity Decomposition (Line 711)
**Difficulty**: Medium-High | **Estimated**: ~20-40 lines | **Depends on**: Sorry 2

Main theorem52_weyl proof. Show:
```
μ({t ∈ G : fract(p*t) ∈ A}) = μ(G) * μ(A)
```

**Implementation approach** (from user guidance):
- Decompose [0, 1) into L periods: [k/L, (k+1)/L) for k = 0,...,L-1
- Use `hG_periodic` to show measure is constant across periods
- On each period, substitution u = t - k/L gives fract(p*(u+k/L)) = fract(p*u)
- Apply `heq_dist` (equidistribution) to each period
- Sum via `MeasureTheory.measure_iUnion`
- Conclude: μ(G) * μ(A)

**Key lemmas**: `hG_periodic`, `heq_dist`, `MeasureTheory.measure_iUnion`, `Set.Ico`
