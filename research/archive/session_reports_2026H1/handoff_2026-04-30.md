#### Setup: Sub-case B2b
- $n = pq$ (distinct odd primes), Unit-Complete, $|E_{\rm div}|=1$, both dropped residues $d_1, d_2 \in H_q$ (multiples of $p$).
- For actual speeds $e_\rho = \rho + q_\rho n$: unit runner $\rho$ has phase $c_\rho(b) = -T_\rho(b)\rho^{-1} \pmod n$, which slides by $-\rho^{-1}$ at each floor step.
- **D1-band of runner $\rho$**: the 2 consecutive floor values $T \equiv -d_1\rho - 1, -d_1\rho \pmod n$ where $\rho$ covers $d_1$. Period $nL/e_\rho$ in fibre space.
- **D2-band**: same but with $d_2$. Separation (D1-start to D2-start in floor-value space): $\text{sep}_\rho = (d_1 - d_2)\rho \pmod n$.
- **Key lemma (proved)**: No unit runner covers $d_1$ and $d_2$ simultaneously (since $d_2 - d_1 = (a_2-a_1)p$ is non-unit, while $\rho^{-1}$ is a unit). So D1-bands and D2-bands are disjoint for each runner.
- **Density**: Total D1-band density $= 2\phi(n)/n = 2(p-1)(q-1)/(pq) > 1$ for $p \geq 3, q \geq 5$ (barely: $16/15$ for $n=15$). So covering $d_1$ alone is capacity-feasible.

#### Core Algebraic Result: Sum-Sep ≡ 0

$$\sum_{\rho \in U} \text{sep}_\rho = (d_1 - d_2)\sum_{\rho \in U} \rho \pmod n$$

Since units pair symmetrically ($\rho \leftrightarrow n - \rho$): $\sum_{\rho \in U} \rho = \phi(n)n/2$, which is a multiple of $n$ (since $\phi(n)$ is even for $n > 2$). Therefore:

$$\sum_{\rho \in U} \text{sep}_\rho \equiv 0 \pmod n$$

**Consequence**: If D1-bands near-tile $\mathbb{Z}/n\mathbb{Z}$ with doubly-covered element $d$, then D2-bands near-tile with doubly-covered element $d' \equiv d \pmod n$, so $d' = d$. **Both tilings must share the same doubly-covered element.**

#### Near-Tiling Framework

For actual speeds with $\gcd(q_\rho, n) = 1$: the floor $T_\rho(kL/n) \pmod n$ is approximately $q_\rho k \pmod n$, which cycles through all of $\mathbb{Z}/n\mathbb{Z}$ as $k = 0, \ldots, n-1$. The D1-band starting position in "integer-fibre space" is $A_\rho \approx (q_\rho)^{-1}(-d_1\rho) \pmod n$ — freely controlled by $q_\rho$.

**D1 near-tiling condition**: The 8 pairs $\{A_\rho, A_\rho+1\}$ (one per unit runner) must cover $\mathbb{Z}/15\mathbb{Z}$ with exactly 1 overlap. (Total elements: $2 \times 8 = 16 > 15 = n$.)

**D2 near-tiling condition**: The 8 pairs $\{A_\rho + \text{sep}_\rho, A_\rho + \text{sep}_\rho + 1\}$ must also cover $\mathbb{Z}/15\mathbb{Z}$ with exactly 1 overlap.

Since D2 starting positions $= $ D1 starting positions shifted by $\text{sep}_\rho$ per runner: the adversary controls $\{A_\rho\}$ (a bijection from runners to $\mathbb{Z}/n\mathbb{Z}$-positions), and the D2 positions are determined by the seps.

#### Extension to Safe Fibre

The D1/D2 gap is a positive-measure interval of fibres. At integer fibres, coverage is constant between floor steps. The remaining runners ($e_0$, $e'$) are:
- $e_0$ transparent at fraction $\geq 1 - 1/n = 14/15$ of fibres.

## The Bijection Impossibility — Proof Sketch for General Case

For general $n=pq$, the seps multiset is $\{(d_1-d_2)\rho \pmod n : \rho \in U\}$. Since $d_1-d_2 = (a_1-a_2)p$ and $\rho$ ranges over units:

- Seps form the set $(a_1-a_2)p \cdot U \pmod n$ — i.e., $(a_1-a_2)$ times the set $\{p\rho \pmod n : \rho \in U\}$.
- Since $\gcd(p, n) = p$: $p\rho \pmod n \in \{p, 2p, \ldots, (q-1)p\} = H_q \setminus \{0\}$ cycling through all non-zero $H_q$-elements as $\rho$ varies.
- Runners with the same residue $\rho \pmod q$ have the SAME sep (since sep depends only on $\rho \pmod q$).
- Within each residue class mod $q$: there are $p-1$ unit runners sharing the same sep value.
- For the bijection $\sigma: P \to P$ with differences from the seps: we need $p-1$ distinct positions $a_i \in P$ all satisfying $a_i + s \in P$ for the SAME sep value $s$. This requires $|P \cap (P - s)| \geq p-1$.
- But $|P| = \phi(n)+1 = (p-1)(q-1)+1$ and $|P - s| = |P|$: the intersection $|P \cap (P-s)|$ for a non-unit shift $s$ is at most $|P| - \text{(gap size)}$.

**The gap**: When $s$ is a multiple of $p$ (which all seps are, since $\text{sep} = (a_1-a_2)p\rho$), the shift $s$ maps elements of $H_q$-type within $P$ to other $H_q$-type elements, but $P$ contains only specific elements. The exact bound requires knowing the structure of $P$.

This is the direction for completing the general proof. It likely requires showing that for at least one sep value $s$, $|P \cap (P-s)| < $ (number of runners with that sep), giving a contradiction. For $n=15$: sep=12 gives $|P \cap (P-12)| = |\{0,2,4,6,8,9,11,13\} \cap \{3,5,7,9,10,12,14,1\}| = |\{9\}| = 1 < 2$ (two runners have sep=12). **Contradiction directly.**
