## Tooling gotchas (learned this session — save yourself the pain)
- **`(j : ℝ)` ascription trap:** in `fun j => ... (j:ℝ) ...` Lean reads `(j:ℝ)` as a
  *type ascription* (forces `j:ℝ`). Fix: annotate the binder `fun j : ℕ =>` and pin
  `(Finset.Icc 1 4 : Finset ℕ)` where `j` is bound externally.
- **Filters over real `<` need NO `open Classical`** — `Real`'s `LinearOrder` gives
  `DecidableLT`. And `open Classical in` *before a doc-comment* fails to parse — just omit it.
- **Renames:** `le_or_lt`→`le_or_gt`; `Set.not_mem_empty`→`Set.notMem_empty`;
  `Int.fract_add_int`→`Int.fract_add_intCast` (and `_natCast`); `Nat.odd_iff_not_even`
  gone (use `← Nat.not_even_iff_odd`).
- **`norm_num` lacks the `Nat.Prime` extension here** → prove `Nat.Prime 5` with `by decide`.
- **`Finset.card_sdiff` is unconditional** in this mathlib: `#(s\t) = #s − #(t∩s)`.
- **`lean_verify` / LSP can report a STALE `sorryAx`** after a `lake build` — trust
  `lake build` + `#print axioms` via `lean_run_code` (reads the fresh on-disk olean).
- **`lean_run_code` "no project path"** error → run any other lean MCP tool first.
- `file-level `open Set` (in IntLRC_5_Bienia) makes bare `univ` = `Set.univ`; qualify
  standalone `univ` as `Finset.univ`.
