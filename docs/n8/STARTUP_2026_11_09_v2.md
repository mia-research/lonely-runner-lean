### 5.1 Core functions (verbatim)

```python
from fractions import Fraction as F
import itertools, random

def chain_of(x):
    """Greedy zone chain over [1,7] for sorted readings x (6 readings rho2..rho7)."""
    rs = [F(v) for v in x]; zones = []
    for idx, r in enumerate(rs):
        j = 1
        while (8*j - 1)/r < 7:
            zones.append(((8*j - 1)/r, (8*j + 1)/r, idx, j)); j += 1
    zones.sort()
    cand = [z for z in zones if z[0] < 1 < z[1]]
    if not cand: return None
    chain = [max(cand, key=lambda z: z[1])]; cur = chain[0][1]
    while cur <= 7:
        opts = [z for z in zones if z[0] <= cur and z[1] > cur]
        if opts: z = max(opts, key=lambda z: z[1])
        else:
            nxt = [z for z in zones if z[0] > cur]
            if not nxt: return None
            z = min(nxt, key=lambda z: z[0])
        chain.append(z); cur = z[1]
    return tuple((z[2], z[3]) for z in chain)

def links_of(chain):
    ls = []
    for k in range(len(chain)-1):
        (p,jp),(q,jq) = chain[k], chain[k+1]
        if p != q: ls.append((p, q, F(8*jq - 1, 8*jp + 1)))
    for i in range(5): ls.append((i, i+1, F(1)))   # order edges
    return ls

def max_cycle(ls):
    """Max product over simple cycles; >= 1 kills strict feasibility."""
    W = {}
    for p,q,w in ls:
        if (p,q) not in W or w > W[(p,q)]: W[(p,q)] = w
    best = F(0)
    for size in range(2,7):
        for cyc in itertools.permutations(range(6), size):
            if cyc[0] != min(cyc) or (cyc[0],cyc[-1]) not in W: continue
            prod, ok = F(1), True
            for a,b in zip(cyc, cyc[1:]+cyc[:1]):
                if (a,b) not in W: ok = False; break
                prod *= W[(a,b)]
            if ok and prod > best: best = prod
    return best
```

### 5.4 Gap-lock LP (needs scipy or any LP; the verification is Fraction)

Variables $(\rho_2..\rho_7, t)$. Rows $a\cdot\rho + \sigma t \le b$:
- **Links** for each overlapping consecutive pair $(p,j_p) \to (q,j_q)$ (overlap at the generating vector: $(8j_p+1)/\rho_p > (8j_q-1)/\rho_q$, or same reading): $-x\rho_q + e\rho_p + t \le 0$ ($e, x$ as above).
- **Gap row** for each NON-overlapping consecutive pair (a gap): $-(8j_p + 1)\rho_q + (8j_q - 1)\rho_p + t \le 0$ — maximize $t$: can the cone close the gap strictly?
- **Strips**: start zone $\rho_{p_0} \le 8j_0 + 1 + t$, $-\rho_{p_0} + t \le -(8j_0 - 1)$; end cap $7\rho_{p_e} + t \le 8j_e + 1$; order $\rho_i - \rho_{i+1} \le 0$; bounds $1 \le \rho_i \le 80$; $t \le 10$.

Solve max-$t$ (float, steering). Take the active support (7 rows), solve the **exact dual**: nonnegative $y$ with $\sum_r y_r a_r = 0$ on all six $\rho$-columns and $\sum_r y_r \sigma_r = 1$; then $t^* = \sum_r y_r b_r$ exactly (7×7 Fraction solve; any subset enumerator works). **LOCKED iff $t^* \le 0$** (the gap cannot close anywhere in the cone — exact kill certificate).
